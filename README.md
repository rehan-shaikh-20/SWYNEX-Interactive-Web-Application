# SWYNEX Interactive Web Application

## Project: SWYNEX Task Manager

A responsive interactive task-management application created for SWYNEX Internship Task 2.

### Technologies
- HTML5
- CSS3
- JavaScript (ES6+)
- Local Storage API

### Task requirements demonstrated
- Interactive frontend functionality
- Reusable UI patterns/components
- Form validation
- State management
- Persistent browser storage

### Features
- Add, edit, complete and delete tasks
- Search tasks
- Filter by All / Active / Completed
- Filter by priority
- Due-date validation
- Dashboard statistics
- Progress indicator
- Local Storage persistence
- Responsive desktop/mobile interface

### Run locally
Open `index.html` in a modern browser.

### GitHub Pages
Repository name:
`SWYNEX-Interactive-Web-Application`

For GitHub Pages, set the deployment source to:
`main` branch → `/ (root)`

No backend is required for this demo; task data is stored in the browser's Local Storage.
